# POG Item Spawner

An in-game item spawner menu for **Pit of Goblin** that lets hosts spawn any item directly into the world or onto their player.

---

## Features

- **Searchable Item List:** Press `F5` to open the overlay and type to filter items in real time.
- **Flexible Spawning:** Spawn items directly into the **World** in front of you or straight onto your **Player**.

---

## Requirements

- **MelonLoader** (Required)

> **Multiplayer Note:** Only the lobby **host/server** can spawn networked items into a match.

---

## Installation

### Mod Manager (Recommended)
1. Install **r2modman** or the **Thunderstore Mod Manager**.
2. Select **Pit of Goblin** and create a profile.
3. Search for **POG Item Spawner** and click **Install** (or import the local `.zip` package via **Settings → Profile → Import local mod**).
4. Click **Start modded**.

### Manual Installation
1. Ensure **MelonLoader** is installed for *Pit of Goblin*.
2. Place `PitOfGoblinSpawner.dll` inside your game's `Mods` folder.

---

## How to Use

1. Start a solo run or host a multiplayer lobby.
2. Press **`F5`** to open or close the **Item Spawner** menu.
3. Type on your keyboard to filter the item list, or click **Clear** to reset the search.
4. Click **World** to drop the item in front of your character, or **Player** to spawn it directly on you.

---

## Configuration (POG Config)

If you have [POG Config](https://thunderstore.io) installed:
1. Open the **Main Menu** or **Pause Menu** and click **MODS**.
2. Select **POG Item Spawner** from the sidebar.
3. Click the **Menu Hotkey** slot to bind any keyboard key or mouse button, or click **RESTORE DEFAULTS** to reset it to `F5`.
